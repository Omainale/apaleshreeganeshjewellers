# 🚀 Quick Start Guide

## Open the Website

Simply open `index.html` in any modern web browser:

1. **Navigate** to `d:\Jellewalary Shop\`
2. **Double-click** `index.html`
3. **Or** right-click → Open with → Your browser

## 🔧 Customization

Want to change something?

### Colors
Edit `css/style.css` lines 10-20:
```css
--cream-bg: #FBF7F2;
--gold-accent: #9A6A2E;
```

### Products
Edit `js/products.js` - Change prices, names, descriptions

### Text Content
Edit any HTML file - All text is plain and visible
